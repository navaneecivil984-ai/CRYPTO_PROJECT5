# 📈 CryptoCast: Multi-Horizon Bitcoin Forecasting

## 📌 Project Overview

CryptoCast is a Deep Learning based Bitcoin Price Forecasting Dashboard developed using Streamlit.

This project compares multiple deep learning models:

* CNN
* RNN
* LSTM
* Transformer

The system predicts future Bitcoin prices for:

* 1-Day Forecast
* 3-Day Forecast
* 7-Day Forecast

It also compares model performances using evaluation metrics and visualization charts.

# 🧠 Models Used

## 1\. CNN (Convolutional Neural Network)

* Captures local patterns in time-series data
* Faster training
* Moderate forecasting accuracy

## 2\. RNN (Recurrent Neural Network)

* Handles sequential data
* Learns previous time steps
* Suffers from vanishing gradient problem

## 3\. LSTM (Long Short-Term Memory)

* Better long-term dependency learning
* High forecasting capability
* Improved accuracy over RNN

## 4\. Transformer

* Best deep learning architecture for sequence modeling
* Captures long-range dependencies
* Highest forecasting performance

\---

# 📊 Evaluation Metrics

* MAE (Mean Absolute Error)
* RMSE (Root Mean Squared Error)
* R² Score

\---

# 🏆 Best Model

Transformer achieved:

✅ Lowest RMSE  
✅ Lowest MAE  
✅ Highest R² Score

Therefore, Transformer is the best model for Bitcoin forecasting.
